# AyOS — сайт

Одностраничный сайт дистрибутива AyOS (React + Vite + Tailwind CSS).

GitHub Pages умеет отдавать только готовые статические файлы и **не собирает `*.tsx`**,
поэтому в репозиторий кладётся уже собранная версия сайта — папка `docs/`.

## Что лежит в репозитории

| Путь | Назначение |
| --- | --- |
| `src/` | исходники (React, TypeScript, CSS, картинки) |
| `docs/` | **готовый сайт для GitHub Pages** — то, что видит браузер |
| `.github/workflows/deploy.yml` | автосборка и публикация через GitHub Actions |
| `vite.config.ts` | сборка сразу в `docs/`, относительные пути к ассетам |

## Публикация на GitHub Pages

### Вариант 1 — автоматически (рекомендуется)

1. Запушьте репозиторий на GitHub (ветка `main` или `master`).
2. Откройте **Settings → Pages**.
3. В поле **Source** выберите **GitHub Actions**.
4. Готово: при каждом пуше workflow соберёт сайт и опубликует его.
   Ссылка появится в **Settings → Pages** и во вкладке **Actions**.

### Вариант 2 — без Actions, прямо из папки `docs/`

1. Откройте **Settings → Pages**.
2. **Source**: **Deploy from a branch**.
3. Ветка **`main`** (или `master`), папка **`/docs`** → **Save**.
4. Через пару минут сайт будет доступен по адресу
   `https://<логин>.github.io/<репозиторий>/`.

Повторная публикация после правок в этом варианте: пересобрать сайт и закоммитить `docs/`.

## Локальная работа

Нужен Node.js 22 и pnpm (версия зафиксирована в `package.json`).

```bash
pnpm install
pnpm dev      # http://localhost:5173 — разработка с горячей перезагрузкой
pnpm build    # собрать сайт в docs/
pnpm preview  # посмотреть итоговую сборку
```

## Как устроена совместимость с GitHub Pages

- `base: './'` в `vite.config.ts` — все ссылки на JS, CSS и картинки относительные,
  поэтому сайт одинаково работает и на `username.github.io/repo/`,
  и на `username.github.io`, и на своём домене. При необходимости базовый путь
  можно переопределить переменной окружения `VITE_BASE`.
- Картинки перенесены из `public/assets` в `src/assets` и импортируются в код —
  Vite сам подставляет правильные пути и добавляет хеш к именам файлов.
- `public/.nojekyll` отключает обработку Jekyll, чтобы GitHub Pages отдавал все файлы как есть.
- Метаданные страницы (`title`, `description`, `favicon`, Open Graph) прописаны прямо в `index.html`.

## Правки контента

- Тексты, редакции и роадмап — `src/App.tsx`.
- Стили и цвета — `src/index.css`.
- Картинки — `src/assets/`.

После любых изменений выполните `pnpm build`, чтобы обновить `docs/`.
